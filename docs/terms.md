## Your responsibility when you use Ghost API

Ghost API explores websites that belong to other people. You decide which sites it visits and
what you do with the results, so you are responsible for making sure your use is lawful and
allowed. In particular:

- **Follow each website's terms of service.** Many sites restrict automated access or the

- **Respect access controls.** Do not use Ghost API to reach data you are not authorised to
  access, or to get around logins, paywalls, bot protection or other technical measures.
- **Do not overload websites.** Keep the built-in rate limits, or stricter ones that a site
  asks for.
- **Handle personal data lawfully.** If the data you collect is about people, the
  data-protection laws that apply to you (for example the EU General Data Protection
  Regulation or India's Digital Personal Data Protection Act, 2023) apply to how you collect,
  store and use it.

  database rights or contracts.

Ghost API has safeguards: it follows `robots.txt`, limits its request rate, refuses to send
requests that change data, refuses to get past bot protection and hides personal data before
storing it. These safeguards help, but they do not make any particular use lawful, and they
